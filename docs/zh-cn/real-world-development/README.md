通过贴近实际的场景、完整应用程序和共享待办事项，了解 GitHub Copilot 如何融入软件开发生命周期。你将迭代规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为桌游众筹提供平台，并以开发者为主题。团队的待办事项已经作为 GitHub issue 建好，等待你领取。其中既有筛选和分页等功能工作，也有无障碍访问和编码规范等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择最适合你的开发环境。每个研讨会都有自己的设置步骤，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

并行运行智能体会话、切换会话模式、在 Canvas 中协作，并在桌面应用中管理 GitHub issue 和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub issue 分配给异步运行的智能体，指导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
