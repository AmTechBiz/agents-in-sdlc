ここまでの 2 つの演習では、ユーザー体験の改善と機能の追加を目的とする 3 つのタスクを Copilot クラウドエージェントに依頼しました。クラウドエージェントは非同期かつ自律的に作業しますが、タスクを監視することも重要です。

クラウドエージェントに割り当てたタスクは、GitHub.com の[エージェント ページ][agents-page]など、さまざまなツールで管理できます。このミッションコントロールには、開いている pull request (PR) があるすべてのエージェントタスクが表示されます。実行内容を確認し、作業中のセッションに追加の指示を出すこともできます。

このレッスンでは、次のことを行います。

- エージェント ページでクラウドエージェントのタスクを監視します。
- 進行中のセッションに追加機能を依頼します。

## シナリオ

エージェントにハイコントラストモードを作成するよう依頼した後、チームはライトモードも追加するとよいと気付きました。サイトのスタイルを更新し、切り替え機能を追加しているため、一緒に実装するのが自然だと考えました。ハイコントラストだけでなくライトモードも追加されるよう、エージェントに指示します。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てたタスクの現在の状態を確認しましょう。

1. [Copilot エージェント ページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインの両方に表示されるタスクの一覧を確認します。次のような、Copilot に割り当てたタスクが表示されます。
   - コードのドキュメントを更新する。
   - ゲームを変更する API を生成する。
   - Web サイトにハイコントラストモードを追加する。
3. 実行中のタスクを選択し、Copilot が行った作業を確認します。次のような内容があります。
   - リポジトリからコードをチェックアウトする。
   - Copilot の作業環境を作成する。
   - MCP サーバーを設定する。
   - 割り当てられたタスクを完了するためのさまざまな手順を実行する。

> [!NOTE]
> 表示される手順は、Copilot の作業状況や実施した方法によって異なります。

4. 右側に表示される pull request (PR) ペインも確認します。PR と変更されたファイルが表示されるため、さらに詳しく監視できます。

## クラウドエージェントに追加の指示を出す

実行中のタスクを確認できました。次は、ハイコントラストモードの作業中にライトモードの切り替えも追加するよう Copilot に依頼します。

1. ハイコントラストモードを追加しているセッションを選択します。正確なタイトルは Copilot が付けた名前や作業状況によって異なります。

    ![ミッションコントロールに表示されたアクセシビリティ セッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業を開始したことが表示されるまで数分待ちます。次の例に似たメッセージが表示されたら、作業が始まっています。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

    ```plaintext
    While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
    ```

    ![Copilot が作業中のアクティブなセッションに追加指示を出すダイアログが強調表示された、エージェント ページのスクリーンショット](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業に追加したことを確認します。

## Copilot の作業を待つ

Copilot は、更新されたタスクに取りかかります。メッセージを送信した時点で作業中だった手順を完了すると、新しい依頼もその後の作業に組み込みます。

この作業にも数分かかります。その間に、ここまでに学んだことを振り返りましょう。

## まとめと次のステップ

Copilot エージェント ページを使って、GitHub Copilot クラウドエージェントのタスクを監視し、ガイドする方法を確認しました。このミッションコントロールでは、進行中と完了済みのタスクを追跡し、実行中の作業を確認して、作業中のタスクに追加の指示を出せます。

このレッスンでは、次のことを行いました。

- ミッションコントロールとエージェント ページでクラウドエージェントのタスクを監視しました。
- 進行中のセッションに追加機能を依頼しました。

Copilot がアクセシビリティ機能を実装したら、次は Copilot が作成した pull request を[反復して改善][next-lesson]します。
