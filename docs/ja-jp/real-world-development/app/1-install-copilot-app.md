**[GitHub Copilot app][about-copilot-app]** は、エージェント主導の開発に使用するデスクトップアプリケーションです。GitHub Copilot CLI を基盤とし、GitHub とネイティブに統合されているため、リポジトリ、ブランチ、CI パイプラインをすぐに利用できます。複数のエージェントに並行して作業を指示し、それぞれの独立したワークスペースで作業させるワークフローに適しています。繰り返し作業を自動化することもできます。Node.js のインストールとプロジェクトの準備ができたので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次のことを行います。

- GitHub Copilot app をインストールしてサインインします。
- GitHub リポジトリからプロジェクトをアプリに追加します。
- テンプレートによって用意されたバックログを含め、ワークスペースを確認します。
- アプリについて簡単なチャットで質問します。

## シナリオ

チームでは、増え続けるバックログに対応するため、AI エージェントを使い始めています。Copilot app では、Issue の取得、エージェントの実行、変更のレビュー、pull request のマージなど、作業全体を一か所から指示できます。このレッスンでアプリをインストールして接続し、プロジェクトについての会話を始める準備をします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、または有料の Copilot プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise を使用している場合、管理者が **GitHub Copilot app** ポリシーを有効にしておく必要があります。

## GitHub Copilot app をインストールして設定する

GitHub Copilot app を使うには、まずインストールします。Windows、macOS、Linux 用のバージョンがあります。アプリをインストールして認証し、Tailspin Toys リポジトリを追加しましょう。

1. ブラウザーで [GitHub Copilot app のランディングページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ランディングページの手順に従ってインストールします。
3. インストール後、アプリを開きます。
4. **Sign in to GitHub** を選択し、画面の指示に従って認証します。データレジデンシーを有効にした GitHub Enterprise Cloud を使う場合は、**Use GitHub Enterprise** を選択し、プロンプトが表示されたら `*.ghe.com` のホスト名を入力します。GitHub Enterprise Server はサポートされていません。
5. オンボーディングでリポジトリを選択するよう求められたら、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリの選択をスキップし、オンボーディングの後に追加することもできます。
6. テーマを選択するよう求められたら選び、オンボーディングを完了します。
7. サイドバーの **Sessions** にリポジトリが表示されていることを確認します。すでに表示されている場合は、再度追加する必要はありません。
8. リポジトリがまだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで控えたリポジトリの所有者名とリポジトリ名を指定します。
9. サイドバーにリポジトリが表示されることを確認します。ここで使用するレイアウトでは、`tailspin-toys` などのリポジトリフォルダーが **Sessions** の下にまとめられ、それぞれのリポジトリの下に個別のセッションが表示されます。

## ワークスペースを確認する

プロジェクトを接続したら、アプリ内を確認しましょう。サイドバーには、主に次の領域があります。

- **New**: プロジェクトのセッションを開始するか、簡単な質問には **Chat** を選択します。
- **Pull requests**: アプリの GitHub ネイティブ統合を通じて pull request を確認できます。アプリを離れずに一覧の表示と絞り込み、CI 状態の確認、レビューを行えます。
- **Issues**: Issue の一覧の表示と絞り込み、Issue からのセッション開始ができます。
- **Automations**: スケジュールまたはオンデマンドで実行する、保存済みのエージェントタスクです。To Do リストの管理、定期的なプロジェクトの保守、その他の面倒な作業を任せるのに便利です。まとめでは次のステップとして紹介しますが、ワークショップ内の演習には含まれません。
- **Customize**: MCP サーバー、プラグイン、スキルなどのコンポーネントを追加して、Copilot app の機能を拡張します。Playwright MCP の設定で使用します。
- **Chats**: 独自のブランチやワークスペースを必要としない、質問やブレインストーミング向けの簡易的な会話です。最初のチャットを開始すると表示されます。表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始します。
- **Sessions**: リポジトリフォルダーと、その中で実行するエージェントセッションがまとめられています。`tailspin-toys` などのリポジトリ名を選択してリポジトリビューを開くか、その下にあるセッションを選択して会話に戻ります。各セッションは独立したワークスペースで実行されるため、変更を競合させずに複数のセッションを実行できます。星評価を追加するレッスンで、最初のセッションを開始します。

ワークショップを進めながら、ワークスペースを確認していきます。

> [!TIP]
> 迷ったときは Copilot に質問しましょう。操作方法が分からない場合や、何かができるか確認したい場合は、Copilot が案内してくれます。

### 用意されたバックログを確認する

バックログのないプロジェクトはほとんどなく、Tailspin Toys も例外ではありません。テンプレートからリポジトリを作成したときに用意されたバックログを確認しましょう。

1. サイドバーの **Sessions** で、個別のセッションではなく Tailspin Toys のリポジトリフォルダーを選択します。次に、リポジトリの上部ナビゲーションで **Issues** を選択します。
2. Issue 番号を決めつけず、タイトルで次の Issue を探します。

   - Allow users to filter games by category and publisher
   - Update our repository coding standards

3. Issue を選択して詳細を読みます。各 Issue はエージェントセッションの開始点にもなります。簡単な最初の変更が終わったら、絞り込みの Issue から作業を始めます。

> [!NOTE]
> **Issues** と **Pull requests** の項目は、Copilot app に追加したリポジトリのものに自動的に絞り込まれます。他のリポジトリの作業項目を確認する場合は、そのリポジトリをアプリに追加してください。

## クイックチャットを試す

アプリ自体について質問すると、アプリに慣れることができます。そのような用途には **クイックチャット** が適しています。クイックチャットでは、ブランチや worktree を作成せずに質問やブレインストーミングができます。セッションを作成せず、手早く質問したい場合に便利です。

1. サイドバーで **Chats** の横にある **+** を選択して新しいチャットを開きます。**Chats** がまだ表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始します。チャットの開始後に **Chats** が表示されます。
2. アプリのセッションの仕組みについて、次の質問をします。

   ```plaintext
   How does the GitHub Copilot app use worktrees?
   ```

3. 会話ビューで回答を確認します。各セッションが独立した Git worktree で実行されるため、変更が競合することなく複数のエージェントを並列実行できることが分かります。会話はいつでも続けることができ、新しいチャットも開始できます。

## まとめと次のステップ

GitHub Copilot app をインストールし、プロジェクトを接続して、ワークスペースを確認しました。次のことを学びました。

- アプリをインストールして GitHub にサインインする。
- GitHub リポジトリからプロジェクトを追加する。
- ワークスペースを確認し、**Issues** で用意されたバックログを見つける。
- クイックチャットで、その場限りの簡単な質問をする。

次は、最初のエージェントセッションを開始し、ゲームカードに星評価を表示します。[最初のエージェントセッションを開始][next-lesson]しましょう。
