Explore o GitHub Copilot em todo o ciclo de vida do desenvolvimento de software, usando cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar alterações, criar código, testar o comportamento, revisar pull requests e gerenciar tarefas com agentes.

## Cenário

Você é uma pessoa desenvolvedora recém-chegada à Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com um tema para desenvolvedores. O backlog da equipe já está registrado como issues do GitHub e pronto para você escolher. Ele inclui tarefas de funcionalidades, como filtragem e paginação, e melhorias de qualidade, como acessibilidade e padrões de código.

## Escolha seu ambiente

O GitHub Copilot acompanha você onde quer que trabalhe. Escolha o ambiente adequado à maneira como deseja desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, MCP do Playwright, Agent Merge e comandos de barra úteis.

### [Aplicativo GitHub Copilot][app]

Execute sessões paralelas de agentes, alterne os modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [Agente GitHub Copilot na nuvem][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, monitore o progresso e revise os pull requests criados.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo Agent do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
